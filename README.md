

# herwall 🌸

> Your wall. Your rules. Your world.

A K-pop poster print shop built for girls in Nepal who love their idols unapologetically. Browse, pick your format, and order directly via WhatsApp.

## Live Site
[herwall.store](https://herwall.store)

## Built With
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Lucide React (icons)
- Vercel (deployment)

## Features
- 22+ K-pop posters across BLACKPINK, BTS, aespa, TWICE, IVE, NewJeans, ITZY
- Filter by fandom
- 3 format options per poster (A4 Framed / Unframed / Bundle)
- Cart with WhatsApp checkout
- Collections: Dark & Moody, Bold & Fierce, Soft & Dreamy
- Fully mobile responsive

## Order Flow
Customer adds posters → selects format → clicks Order via WhatsApp → message sent directly to herwall
